# Shelomi Fashions — GitHub Pages Website

This is a multi-page, mobile-first responsive static website.

## Pages
Home, Collections, Women, Men, Children, Services, About, Contact.

## Publish on GitHub Pages (phone-friendly)
1. Create a **public** GitHub repository named `shelomi-fashions`.
2. Extract this ZIP on your phone.
3. Open the extracted folder and upload the files and folders inside it directly to the repository root (do not upload only the outer folder).
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then Save.
7. Wait for GitHub Pages to publish. Your address will be `https://YOUR-USERNAME.github.io/shelomi-fashions/`.

## Important
GitHub Pages is free static hosting. It does not provide a database, server-side backend, secure admin dashboard, payment processing or full e-commerce checkout. The current contact flow uses WhatsApp, phone and email. Replace any social links with your real profile links when you have them.

## Responsive features
Mobile navigation menu, flexible layouts, mobile/tablet/desktop breakpoints, readable scaling typography, responsive cards and accessible reduced-motion support.
